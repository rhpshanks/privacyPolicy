# Sort Squad privacy policy

The public privacy policy for the Android game **Sort Squad**
(`com.hashaamshahid.sortsquad`), served through GitHub Pages.

`index.html` is the page itself. It is self contained: no scripts, no fonts, no
external requests of any kind.

## Publishing

1. Push this repository to GitHub as a **public** repository.
2. Settings, then Pages, then set Source to `Deploy from a branch`, branch `main`,
   folder `/ (root)`.
3. The policy appears at `https://<username>.github.io/sortsquad-privacy/`.

That URL goes in two places: the Play Console listing, and `GameConfig.PrivacyPolicyUrl`
in the game project.

## Editing

Edit `index.html` directly and push. The Markdown original lives with the game project
at `StoreAssets/privacy-policy.md`; keep the two in step if you change the wording.
